Why sports-skills

Built for agents, not dashboards.

Every skill is a SKILL.md your agent loads on demand, backed by a Python SDK that answers in the same shape for every sport and every venue.

{{ m.icon("braces") }}

One envelope, every sport

Scores, standings, play-by-play, odds and order books all come back as status, data and message — so one parser handles {% if site and site.module_count %}{{ site.module_count }}{% else %}every{% endif %} modules.

$ sports-skills betting devig --odds="-150,+130"
{
  "status": true,
  "data": { "vig_pct": 3.48, "outcomes": [ … ] },
  "message": "Vig: 3.48% | Fair probs: 58.0%, 42.0%"
}
